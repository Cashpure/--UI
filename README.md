# ЦентрКонсалт — интерфейс отдела продаж

Интерфейс для просмотра обращений, поиска устройств и управления их статусами. Создан на HTML, CSS и JavaScript.

## Как открыть

Откройте `index.html` в браузере. Для размещения на GitHub Pages загрузите файлы вместе, сохранив их относительные пути. Сборка не требуется.

## Работа с устройствами

1. Найдите устройство по телефону или цифровому слепку. Для просмотра статусов используйте фильтры «Все», «Активные» и «Заблокированные».
2. Выберите строку, чтобы увидеть подробности и историю обращений.
3. Нажмите «Заблокировать устройство», укажите причину и подтвердите действие.
4. При необходимости нажмите «Разблокировать устройство».
5. Перейдите в раздел «Экран посетителя», чтобы посмотреть предупреждение и форму обращения.

Кнопка «Сбросить изменения» возвращает исходные статусы. Цветовую тему можно переключить в верхней панели.

## Файлы

- `index.html` — структура страниц.
- `styles.css` — оформление и цветовые темы.
- `app.js` — записи и действия интерфейса.
- `assets/ck_logotype_new.svg` — логотип в разделе «Экран посетителя».
