# ЦентрКонсалт — интерфейс отдела продаж

Интерфейс для просмотра обращений, поиска устройств и управления их статусами. Создан на HTML, CSS и JavaScript.

## Как открыть

Откройте `index.html` в браузере для работы с устройствами. Страница для посетителя открывается напрямую через `visitor.html`. Для размещения на GitHub Pages загрузите файлы вместе, сохранив их относительные пути. Сборка не требуется.

## Работа с устройствами

1. Найдите устройство по телефону или цифровому слепку. Для просмотра статусов используйте фильтры «Все», «Активные» и «Заблокированные».
2. Выберите строку, чтобы увидеть подробности и хронологию устройства. В ней показаны отправленные и отклонённые заявки, блокировки, разблокировки, ссылки на страницы отправки и все заполненные поля.
3. Нажмите «Заблокировать устройство», укажите причину и подтвердите действие.
4. При необходимости нажмите «Разблокировать устройство».
5. Откройте `visitor.html`, чтобы посмотреть предупреждение и форму обращения для посетителя.

Кнопка «Сбросить изменения» возвращает исходные статусы. Цветовую тему можно переключить в верхней панели.

## Файлы

- `index.html` — страница отдела продаж.
- `visitor.html` — страница посетителя.
- `styles.css` — оформление и цветовые темы.
- `app.js` — записи и действия отдела продаж.
- `visitor.js` — действия на странице посетителя.
